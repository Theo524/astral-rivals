# Game downloads

## Windows PC

**[Download Windows game ZIP](https://github.com/Theo524/astral-rivals/raw/refs/heads/main/downloads/AstralRivals-Windows-0.2.0.zip)**

1. Right-click the downloaded ZIP and choose **Extract All**.
2. Open the extracted `AstralRivals` folder and double-click **AstralRivals.exe**.
3. Start with **Training**. Use WASD to move, J to attack, K for heavy, L for blasts, E for a beam, C to charge, and Esc to pause.

This standalone x64 testing build includes the game data and runtime; no Godot installation or separate PCK is needed. The real executable launched and rendered under Wine; physical Windows hardware and gamepad compatibility remain unverified.

## Android

[Download Astral Rivals APK](https://github.com/Theo524/astral-rivals/raw/refs/heads/main/downloads/AstralRivals-Android-0.2.0.apk)

For 64-bit Android 7 or newer. Open the downloaded APK from Files to install. No Godot editor is required.

This is version 0.2.0, a development-signed testing build. Its packaging and signatures were checked; physical Android device testing, performance and the reported Android-editor crash cause remain unverified.

If you opened a binary file page on GitHub, choose **Download raw file**. Checksums and Godot runtime notices are included in this folder and the Windows ZIP.
